# 구현 구조

## 인식과 피드백

단어 인식 TCN은 영상이 어떤 단어와 가까운지를 분류합니다. 세부 피드백은 별도 시간 합성곱·GRU 및 세부 판정부에서 손모양과 행동 흐름을 관측하고, DTW 대응·신체 상대 위치·행동 완료 근거를 결합합니다. 분류 점수 자체를 행동의 정답률이나 교정 정확도로 해석하지 않습니다.

현재 정면 피드백의 주요 구현 경로는 다음과 같습니다.

```text
frontal_demo_launcher.py
  → capture_feedback_completion_20261116/
      moa_coaching_room_20261117/motion_dock_20261117/serve.py
  → 기존 검증된 촬영·정면 판정·선택 재검출 모듈 재사용
  → site/ 의 MOA·참고 시범·촬영·결과 UI
```

위 연구 폴더의 전체 접두사는 `research/front_keyphase_v1/ops/`입니다. 현재 코드가 이전 날짜의 모듈을 재사용하므로, 과거 폴더를 날짜만 보고 삭제하면 안 됩니다.

## 시각적 안내

연습에서는 참고 캐릭터와 사용자 촬영을 연결하고, 차이가 관측된 손·팔과 해당 구간을 강조합니다. 문장은 검증된 판정 결과에 맞는 짧은 안내를 사용합니다. 관절 누락, 손모양의 불확실성, 확인된 행동 차이는 구분합니다.

## 현재 한계

- 관절점이 존재해도 정확한 손가락 위치라는 보장은 없습니다. 가림·교차·정면 투영의 모호함이 남습니다.
- 세부 행동 정답의 범위는 전체 단어 인식 학습 범위보다 좁습니다.
- 정상 수행의 공개 평가와 실제 사용자의 의도적인 오류에 대한 교정 평가는 다릅니다.
- 다른 PC와 외부 다중 사용자 환경에서의 실행은 별도 검증이 필요합니다.
- 정면 관절만으로 확정할 수 없는 접촉·깊이·가려진 손가락은 억지로 정답 또는 오답 처리하지 않습니다.

여러 시점의 영상은 캐릭터 애니메이션 복원에 사용합니다. 사용자의 피드백 입력을 다중 카메라로 가정하지 않습니다.
