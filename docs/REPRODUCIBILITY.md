# 실행과 재현 범위

이 공개본은 코드 검토와 연구 구조 공유를 위한 소스 기록입니다. 가중치와 데이터가 제거되어 단독 실행·전체 테스트 통과를 보장하는 배포판은 아닙니다.

## 별도로 필요한 것

1. Python 실행 환경 및 RTMW/OpenVINO·단어 인식·세부 피드백 의존성.
2. 학습된 가중치와 코드의 검증 계약 파일. 공개본에서 제외했습니다.
3. 적법하게 확보한 AI Hub 공개 학습 자료, 필요한 설명·정답 주석 및 참고 영상.
4. 사용 권한을 확인한 캐릭터·애니메이션·웹 라이브러리 자산.
5. 환경별 경로 설정과 공개 자료를 이용한 재현 검증.

`runtime-environment.json`은 개발 환경에서 읽은 주요 패키지 버전입니다. 설치와 실행이 검증된 이식용 lock 파일은 아닙니다.

## 현재 개발 환경의 진입점

원래 개발 환경에서는 `START_WEB_DEMO.cmd`가 로컬 Python과 `frontal_demo_launcher.py`를 실행하며, 브라우저에서 `http://127.0.0.1:8821/`로 접근합니다. 게시본에 적힌 일반화된 사용자 경로는 실제 환경에 맞게 설정해야 합니다.

Unity 쪽에는 `Packages/manifest.json`, `Packages/packages-lock.json`, `ProjectSettings/`를 포함했습니다. 비공개·외부 자산과 일부 테스트 자료는 제외했으므로 단순 복제 후 Unity 빌드가 완료되는 상태는 아닙니다.

## 배포와의 구분

GitHub에 소스를 올린 것과 인터넷에서 게임을 실행하게 하는 것은 다릅니다. 현재 웹 서버는 로컬 PC의 카메라와 Python 추론을 사용합니다. 정적 호스팅만으로 방문자의 관절 추출·추론이 실행되지는 않습니다.

외부 시연 준비에서는 모델 실행 위치, 영상의 메모리 처리, 사용자별 세션 분리, 촬영 종료 후 대기시간, 다른 Windows PC의 실행 조건을 별도로 검증해야 합니다.
