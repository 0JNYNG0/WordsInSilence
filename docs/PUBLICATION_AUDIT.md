# 공개 전 검사

2026-11-26 게시 준비 기준입니다.

1. 개발 원본과 전체 백업을 그대로 두고 공개용 사본을 별도로 만들었습니다.
2. 영상·사진·좌표 CSV/배열·모델 가중치·설치 환경·브라우저 프로필을 제외했습니다.
3. 개별 기록의 테스트 매니페스트, 좌표 주석 및 내부 인수인계 자료도 제외했습니다.
4. 코드의 개인 PC 경로와 Unity 계정 식별자를 일반화하거나 비웠습니다.
5. 게시 이력은 같은 파일 정책으로 재구성하며, 개발용 Git의 미검토 커밋을 그대로 업로드하지 않습니다. 커밋 작성자 연락처는 GitHub 비공개 이메일 형식을 사용합니다.
6. Gitleaks의 전체 게시 이력 검사와 별도 파일 유형·경로·내장 미디어 검사를 수행합니다.

초기 비밀키 검사에서 관절 필드명 비교와 고정 오류 문구가 15건 오탐으로 표시됐습니다. 원문 코드에서 인증과 관계없는 값임을 확인했고, `.gitleaks.toml`에는 해당 파일과 해당 줄의 문법만 정확히 지정했습니다. 파일 전체나 커밋 전체를 검사에서 제외하지 않습니다.

Python 행렬곱 연산의 `@`와 속성 이름을 이메일로, Unity의 내부 숫자 식별자를 전화번호로 오인한 항목도 코드 문맥으로 구분했습니다.

자동 검사만으로 모든 개인정보나 재배포 권리를 증명할 수는 없습니다. 불확실한 데이터·외부 자산은 공개하지 않는 원칙을 적용했습니다. 합성 수치 테스트는 실제 사람의 관절 기록과 구분합니다.

원본 실행 환경의 모델·C·T3-F·입출력·사용자 촬영 자료는 이번 게시 정리에서 변경하거나 학습에 사용하지 않았습니다. 공개용 사본의 전체 실행·학습을 새로 검증한 것은 아닙니다.
