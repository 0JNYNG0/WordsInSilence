# 데이터와 개인정보 공개 정책

## 공개하는 범위

자체 코드, 필요한 프로젝트 설정, 일반화된 설명 문서, 공개 전 검사 요약을 공개합니다.

## 공개하지 않는 범위

- 사용자 및 테스트 참여자의 영상·이미지·음성·관절 배열·촬영별 진단 결과.
- 데이터셋 원본 영상·이미지·ZIP, 개별 기록을 담은 매니페스트와 파생 좌표 자료.
- 모델 가중치와 원본 데이터에 대한 권한 확인이 필요한 외부 자산.
- 인증 정보, 환경 변수 값, 브라우저 프로필, 로컬 계정명과 개인 경로.
- 대화 이력, 내부 작업 인수인계, 로컬 백업 및 전체 개발 Git 이력의 미검토 자료.

실제 개인 촬영은 학습·튜닝·후보 선택에 사용하지 않습니다. 공개 원천 자료로 학습했다는 사실이 원천 자료 자체의 재배포를 자동으로 허용한다는 뜻은 아닙니다.

## 게시와 실행의 차이

개인 데이터가 이 저장소에 없다는 것은 현재 개발용 프로그램이 촬영 데이터를 전혀 저장하지 않는다는 뜻이 아닙니다. 개발용 서버에는 로컬 진단 저장 경로가 있습니다. 방문자용 미보관 배포는 촬영·재검출·비교 재생 경로를 함께 변경하고 검증해야 합니다.

## 변경 시 확인

촬영 결과 폴더를 통째로 추가하지 않습니다. 코드 파일 안에 들어 있는 실제 관절 배열, 캡처 이미지, 개인 경로도 확인합니다. 공개용 사본과 전체 개발 사본의 Git 이력을 직접 합치지 않습니다.

자동 비밀키 검사는 데이터 내용 검토를 대신하지 않습니다. 원천 자료와 캐릭터 등 제3자 자산은 해당 출처의 이용 조건을 확인한 뒤 별도로 관리합니다.
